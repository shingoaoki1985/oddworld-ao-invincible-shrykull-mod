## Game data

No Oddworld executable, level archive, original movie, sound, save file, extracted font atlas, or other extracted game-data file is included in this repository. The repository includes a short gameplay recording captured by the user solely to demonstrate the modification.

`tools/Extract-JapaneseFontAtlas.ps1` only supports the explicitly verified Steam Japanese executable hash. It creates a small coordinate table locally from the user's legally obtained installation. Do not commit or redistribute the generated `japanese_font_atlas.bin` unless you have independently determined that you have the necessary rights.
